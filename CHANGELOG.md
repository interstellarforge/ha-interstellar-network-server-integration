# Changelog

## 0.3.0

- Renamed the product and Home Assistant integration to **Interstellar Network**.
- Canonicalized the integration domain as `interstellar_network`.
- Renamed the HACS/GitHub repository target to `home-assistant-interstellar-network`.
- Renamed the dashboard card to `custom:interstellar-network-card`.
- Renamed the dashboard title to **Interstellar Network**.
- Updated manufacturer, diagnostics metadata, documentation, workflows, release artifacts,
  entity metadata, and user-facing strings to the canonical name.

## 0.2.0

- Added server roles and expected-service policy.
- Added package/security update telemetry.
- Added boot time.
- Added network RX/TX statistics.
- Added disk I/O and filesystem inode metrics.
- Added CPU iowait and steal metrics.
- Added OOM and failed-service counters.
- Added Home Assistant Repairs issues.
- Added Interstellar Network dashboard card.
- Improved auto-discovery support.

## 0.1.0

- Initial Home Assistant integration.
- CPU, memory, disk, uptime and service sensors.
- Tailscale/LAN addressing and Zeroconf discovery.
